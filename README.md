# 📰 Smart Fake News Detection System

## 📌 Project Overview

The **Smart Fake News Detection System** is a machine learning-based web application designed to identify misleading and fake news articles. It uses Natural Language Processing (NLP) techniques and machine learning algorithms to classify news content as **Real or Fake**.

The application provides a simple and interactive interface built with Streamlit, allowing users to enter a news headline and article content and receive an instant prediction with a confidence score.

## 🎯 Objectives

- Detect fake and misleading news articles.
- Apply NLP techniques to process textual data.
- Use machine learning for news classification.
- Provide an easy-to-use interface for users.
- Display prediction results and maintain prediction history.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Machine Learning:** Logistic Regression
- **NLP:** TF-IDF Vectorization
- **Libraries:** Pandas, Scikit-learn, Joblib
- **Web Framework:** Streamlit
- **Dataset:** WELFake Dataset

## ✨ Key Features

- Real-time fake and real news detection.
- Headline and article text input.
- Prediction confidence score.
- Interactive dashboard.
- Prediction history tracking.
- CSV download for prediction history.
- Simple and user-friendly interface.

## ⚙️ Machine Learning Workflow

1. Load and prepare the news dataset.
2. Clean and preprocess the text data.
3. Convert text into numerical features using TF-IDF.
4. Train the Logistic Regression model.
5. Evaluate model performance.
6. Save the trained model using Joblib.
7. Integrate the model with the Streamlit application.

## 📊 Model Performance

- **Algorithm:** Logistic Regression
- **Vectorization:** TF-IDF
- **Accuracy:** 94.80% (as recorded in the project dashboard)

## 🚀 How to Run the Project

**Step 1: Clone the repository**
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Navigate to the project folder**
```bash
cd Smart-Fake-News-Detection-System
```

**Step 3: Install dependencies**
```bash
pip install streamlit pandas scikit-learn joblib
```

**Step 4: Run the application**
```bash
streamlit run app.py
```
